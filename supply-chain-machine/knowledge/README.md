# Supply Chain Machine: evidence-backed reasoning library (v0.1)

This is a curated **starter**, not 20 fully reviewed cases or a trained knowledge engine.

- cases.json: five real, publicly traceable examples; gated case abstracts are marked.
- rules.json: eight candidate operational rules with triggers, alternatives, validation questions, and case provenance.
- Evidence hierarchy: observed company fact > documented case example > cross-case inference > unsupported assumption.
- A rule is a *hypothesis generator*, never proof of a company's actual routes.
- R003 (shared domestic/import distribution) is deliberately marked as an inference, relevant to Andros but unverified.
- Next: wire rule retrieval to Build Hypothesis, validate rule applicability, add counterexamples, and expand to 20 source-reviewed cases.

No copyrighted case text is reproduced. The descriptions are short original summaries with links.
