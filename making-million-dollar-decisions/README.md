# Making Million-Dollar Decisions

University of Hartford interactive workshop on problem framing, constrained optimization, AI analysis, and storytelling.

Planned files: `index.html` (ten-slide presentation built around a sealed decision bet), `activities.html` (interactive exercises).

Illustrative decision: whether and where to open a $30M distribution center, with $4M annual operating costs.

Publish using GitHub Pages from the main branch root. Do not put AI API keys in client-side HTML.
