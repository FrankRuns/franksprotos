# Shortcuts for Life

University of Hartford two-hour workshop: product thinking, optimization, AI agents, and storytelling.

Planned files:
- `index.html`: seven-slide presentation
- `activities.html`: four hands-on activities

To publish with GitHub Pages, configure Pages to deploy from the `main` branch and `/ (root)` folder. The workshop will then be available at `/shortcuts-for-life/` once `index.html` is added.

Do not embed API secrets in browser HTML. Use a secure server-side endpoint for AI requests.
